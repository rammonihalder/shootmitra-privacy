ShootMitra Privacy Policy - GitHub Pages

1. Create a PUBLIC GitHub repository named: shootmitra-privacy
2. Upload index.html to the root of the repository.
3. Open repository Settings > Pages.
4. Under Build and deployment, choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
5. Save.
6. Wait a short time for GitHub Pages deployment.
7. Your URL will normally be:
   https://YOUR-GITHUB-USERNAME.github.io/shootmitra-privacy/

Use that URL in Google Play Console > Privacy Policy.
